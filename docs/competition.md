# Amazon Developer Hackathon

AmFire by TensorVerseAI connects a Fire TV viewing moment, a Bee wish, Alexa-assisted selection and a Ring arrival story.

- Public demo: https://amfires.com/
- Public source: https://github.com/TensorVerseAI/AmFire
- Setup: see the root README. No credentials are needed for the synthetic guest demo.
- Submission deadline: October 23, 2026, 19:00 UTC.
- Presentation asset: the owner-supplied 83.36-second explainer is public at https://amfires.com/assets/amfire-presentation.mp4. It is a concept presentation, not proof of the required device/integration execution; final contest submission selection is still pending.
- Evidence still required: Fire TV device/simulator execution, real Bee or Bee-on-Apple-Watch data, and demonstrated Ring integration or official simulator. Alexa+ simulation is permitted, but the current public sample is not proof of a working Agent Skill or MCP integration.
- Current purchases, delivery/reaction and product suggestions are simulated. No real purchase occurs.

[Official rules](https://amazonappdev2026.devpost.com/rules), checked October 16, 2026, govern eligibility and submission. Judges must receive all source, assets and instructions necessary to run the submitted project. A private repository must be shared with the reviewers specified in those rules; a public frontend alone cannot conceal required implementation from judges. No submission or invitations have been made by this repository.

See [repository boundaries](repository-boundaries.md) for the established public/private boundary.
