# Exact-artifact review

Synthetic ground truth: `public/assets/scene.svg` depicts one orange backpack on a wooden bench in a warm room. Brand, model, ASIN, size, real price, stock and purchase eligibility are intentionally unknown. A VLM must distinguish these observable features from inferred retail identity. This is NOT a Fire Stick capture.

Bind review to source commit, frontend file hashes, screenshot hash, viewport and functional-log hash. Verify Start, fullscreen application shell, menu during video, panel opening, exit, video playback, public chat, product-category link, checklist validation, no order claim, browser-specific install fallback and server auth rejection. Screenshots are not device execution proof or backend evidence.

Independent visual review supplements functional tests; it does not certify product identity. Use only authorized images, keep provider usage bounded, and reuse evidence only when relevant hashes are unchanged.
